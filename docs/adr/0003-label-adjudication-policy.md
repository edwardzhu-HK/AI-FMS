# ADR 0003: Segment Label Adjudication Policy

## Status

Accepted

## Context

Calibration 的目标不是只存一个分数，而是通过三方评分沉淀高质量训练标签:

- AI 评分
- 人工审核员 A 评分（认证 FMS 训练师）
- 人工审核员 B 评分（认证 FMS 训练师）

在评分不一致时，需要明确可执行且可审计的标签裁决规则。

## Decision

片段级裁决规则如下:

1. 每个片段必须存储 `AI`、`A`、`B` 三份原始评分（至少总分；细分项可选保留）。
2. 若 `A == B`，最终标签采用人工一致分（`human_consensus`）。
3. 若 `A != B` 且 `AI == A` 或 `AI == B`，最终标签采用与 AI 一致的人工分（`ai_human_match`）。
4. 若三者都不一致，标记为无效样本（`invalid`），不进入训练标签集。
5. 无效样本仍保留全部原始记录与审计字段。

## Consequences

优点:

- 规则明确，可直接自动化执行
- 保留全部原始信号，便于后续回溯
- 为 AI 校准提供稳定标签来源

代价:

- 需要实现更严格的数据校验和状态管理
- 无效样本会累积，需后续复核策略

## Follow-up

- 校准训练仅使用 `valid` 样本。
- 每次校准必须记录一致率变化和模型版本。
