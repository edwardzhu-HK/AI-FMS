# OpenAI Developer Community 发布指引

## 发布前定位

这篇不是论文摘要，也不是产品广告。最合适的定位是 Ronnie 的开发复盘：Codex 帮助了什么、哪里会犯“看上去很完整”的错误、为什么人必须负责协议和结论。

## 发布步骤

1. 用 Ronnie 的 OpenAI Developer Community 账号登录 [community.openai.com](https://community.openai.com/)。
2. 先搜索 `Codex human-in-the-loop computer vision project`，确认没有同内容的旧帖。
3. 点击新建 topic，优先选择 `Codex` category。
4. 复制 `AI-FMS_OpenAI_Developer_Community_Post.md`，在编辑器中检查 Markdown 标题、列表和图片。
5. 使用当前论坛存在的 tags；建议 `projects`、`human-in-the-loop`、`computer-vision`、`sports-tech`，不存在的就删掉。
6. 上传 package 中经过检查的三张图，替换文内本地图片链接。
7. 填入 Zenodo DOI、GitHub、public demo 和视频 URL。
8. 预览手机和桌面宽度，确认图片、标题、列表和链接正常。
9. Ronnie 自己完整朗读一遍，把不像他本人语气的句子改掉。
10. 发布后，用准备好的 first reply 补充 Zenodo 方法链接并邀请技术讨论。

## 隐私和安全检查

- 不公开 API key、token、账号信息、session、未打码日志或本机完整路径。
- 不上传 raw video、reviewer comments、数据库、source manifest 或带人物身份信息的截图。
- 不重复发到多个 category，也不要连续发宣传帖。
- 文章结尾保留 AI disclosure 和 non-clinical boundary。

## 互动策略

- 对技术问题可以公开回答；涉及个人数据、认证账号或私密素材的问题不要在帖子里展开。
- 有重大更新时在原帖增加一条更新，不新开重复主题。
- 如果有人质疑 16/25，不要防御性解释。直接说明这是 internal post-audit，下一步是 held-out 和 randomized assistance study。
